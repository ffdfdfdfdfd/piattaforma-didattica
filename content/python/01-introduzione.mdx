## Cos'è Python

Python è un linguaggio di programmazione ad alto livello, interpretato e con tipizzazione dinamica. È stato creato da Guido van Rossum e pubblicato per la prima volta nel 1991. Oggi è uno dei linguaggi più usati al mondo, in ambiti che vanno dallo sviluppo web all'analisi dei dati, dall'automazione all'intelligenza artificiale.

Alto livello significa che le istruzioni sono vicine al linguaggio umano e nascondono i dettagli della memoria e del processore. Interpretato significa che il codice viene eseguito riga per riga da un programma chiamato interprete, senza una fase separata di compilazione in un file eseguibile. Tipizzazione dinamica significa che il tipo di una variabile viene deciso quando il programma gira, non quando lo scrivi.

Queste scelte hanno un prezzo e un vantaggio. Il prezzo è che Python è più lento di C o Rust in termini di puro calcolo. Il vantaggio è che si scrive molto meno codice per ottenere lo stesso risultato, e gli errori logici emergono più tardi, durante l'esecuzione.

## Come funziona l'esecuzione

Quando lanci un programma Python, succedono tre cose in sequenza:

1. L'interprete legge il file `.py` e lo traduce in bytecode, una rappresentazione intermedia.
2. Il bytecode viene eseguito da una macchina virtuale, la PVM (Python Virtual Machine).
3. Il risultato, se c'è, viene mostrato a schermo.

Il file `.pyc` che a volte trovi nella cartella `__pycache__` è proprio il bytecode già tradotto: serve a non rifare la traduzione la prossima volta.

## Il primo programma

Apri un editor di testo, scrivi questa riga e salva il file come `ciao.py`:

```python
print("Ciao, mondo")
```

Apri il terminale nella cartella del file ed esegui:

```
python ciao.py
```

Vedrai stampato a schermo:

```
Ciao, mondo
```

`print` è una funzione incorporata. Le parentesi contengono quello che vuoi mostrare. Le virgolette dicono a Python che quella sequenza di caratteri è una stringa, cioè testo.

## Differenza tra script e REPL

Puoi anche lanciare solo:

```
python
```

Si apre il REPL (Read-Eval-Print Loop). Vedi un prompt `>>>` e puoi scrivere istruzioni una alla volta:

```
>>> 2 + 3
5
>>> print("ciao")
ciao
>>> nome = "Marco"
>>> nome
'Marco'
```

Il REPL è comodissimo per provare piccole cose. Lo script serve invece quando il programma diventa lungo o quando vuoi salvarlo e riutilizzarlo.

## Commenti

Un commento inizia con `#` e arriva fino a fine riga. Python lo ignora.

```python
# Questo è un commento
print("ciao")  # anche questo è un commento
```

I commenti servono a spiegare il perché di una scelta, non a ripetere quello che il codice già dice. Un commento inutile è peggio di nessun commento.

## Errori comuni

**Dimenticare le virgolette.** Se scrivi `print(ciao)` invece di `print("ciao")`, Python cerca una variabile chiamata `ciao` e non la trova:

```
NameError: name 'ciao' is not defined
```

**Dimenticare le parentesi.** In Python 3 `print` è una funzione, quindi le parentesi sono obbligatorie. `print "ciao"` dà:

```
SyntaxError: Missing parentheses in call to 'print'
```

**Usare la maiuscola sbagliata.** Python distingue maiuscole e minuscole. `Print` non esiste. `nome` e `Nome` sono due variabili diverse.

**Indentazione a caso.** In Python l'indentazione non è decorativa: definisce i blocchi. Se metti uno spazio di troppo all'inizio di una riga senza motivo, ottieni:

```
IndentationError: unexpected indent
```

## Buone pratiche

- Dai al file un nome che descriva cosa fa, con parole separate da underscore: `calcola_media.py`, non `prova.py`.
- Non usare accenti o spazi nei nomi dei file. Meglio `perche.py` che `perché.py`.
- Salva i file in una cartella dedicata al progetto.
- Esegui sempre lo script dal terminale almeno una volta, anche se usi un IDE: capire cosa succede sotto è parte dell'imparare.

## Scorciatoie utili

A seconda dell'editor che usi:

| Azione | VS Code (Windows/Linux) | VS Code (macOS) |
|---|---|---|
| Esegui il file aperto | Ctrl + F5 | Cmd + F5 |
| Apri il terminale | Ctrl + ò | Cmd + ò |
| Salva | Ctrl + S | Cmd + S |
| Commenta la riga | Ctrl + / | Cmd + / |

Nel terminale:

| Comando | Cosa fa |
|---|---|
| `python --version` | Mostra la versione di Python |
| `python file.py` | Esegue il file |
| `python` | Apre il REPL |
| `exit()` | Chiude il REPL |

## Esercizi guidati

**Esercizio 1.** Scrivi un file `presentazione.py` che stampa a schermo il tuo nome.

Soluzione:

```python
print("Marco")
```

**Esercizio 2.** Modifica il file in modo che stampi nome e città su due righe separate, usando due chiamate a `print`.

Soluzione:

```python
print("Marco")
print("Torino")
```

**Esercizio 3.** Aggiungi un commento sopra ogni `print` che spieghi cosa stai stampando.

Soluzione:

```python
# Stampa il mio nome
print("Marco")

# Stampa la mia città
print("Torino")
```

## Esercizi autonomi

1. Scrivi uno script che stampi il tuo nome, la tua età e la tua classe, ognuno su una riga.
2. Prova a scrivere `print("ciao"` senza chiudere la parentesi ed esegui. Copia l'errore che ottieni e cerca di capire cosa ti sta dicendo.
3. Apri il REPL e calcola a mano `7 * 6`, `100 / 4`, `2 ** 10`. Poi esegui le stesse operazioni in un file `.py` e confronta i risultati.

## Riepilogo

- Python è un linguaggio interpretato, ad alto livello, con tipizzazione dinamica.
- Un programma si scrive in un file `.py` e si esegue con `python file.py`.
- Il REPL permette di provare istruzioni una alla volta.
- `print()` mostra testo a schermo.
- I commenti iniziano con `#`.
- L'indentazione in Python fa parte della sintassi.
